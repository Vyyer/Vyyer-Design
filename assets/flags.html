Flag assets

One SVG per country, in assets/flags/, named by ISO 3166-1 alpha-2 code. Use these instead of flag emoji — Windows ships no colour flag glyphs, so emoji flags render as two letters in a box there. Click a tile to download that one; take the whole folder for the set. flags/countries.json maps every code to its name, emoji and file. Twemoji, CC-BY 4.0 — see README.md.
